1) Что за сервис: учебный сервис **предварительной оценки заявки на заём под ПТС** (carmoney-lab, практикум М3) — принимает заявку (VIN, год, пробег, оценочная стоимость, сумма, срок), считает LTV и возвращает решение `approve` / `review` / `reject`; все данные синтетические.
2) Команды запуска и проверки: в `Makefile` — `make up` (`docker compose up -d --build`, сервис на http://localhost:8080, MySQL 8), `make down`, `make test` (PHPUnit), `make lint` (`php -l` по `backend/` и `tests/`), `make seed` (перезалить `db/seed.sql`), `make install`, `make ps`, `make logs`, `make help`; в `docker-compose.yml` явно прописаны только эти `docker compose …` вызовы через Makefile — отдельной секции `command:` / `healthcheck:` для ручного `docker compose run` не нашёл.
3) Решение `approve / review / reject` считается в папке `backend/src/Domain/` — там `DecisionEngine.php`, `LtvCalculator.php`, `AssessmentService.php`; пороги/лимиты берутся из `backend/config/rules.php`.
